Скрывает часть описания категории WooCommerce белым градиентом, если описание превышает заданное количество символов.

== Description ==

Плагин скрывает визуально часть описания категории товаров WooCommerce белым градиентом (от прозрачного сверху к белому снизу), если описание превышает заданный лимит символов. Слева снизу появляется кнопка «Читать подробное описание категории». Полный текст остаётся в DOM — SEO не страдает.

Настройки доступны в разделе **Одиноков → CatReadMore**:
* Лимит символов
* Текст кнопки
* Шрифт кнопки, жирность шрифта
* Цвет фона, цвет и толщина границы
* Закругление углов, внутренние отступы
* Иконка кнопки (загрузка через медиабиблиотеку)
* Отступы описания в закрытом и открытом состоянии
* Высота градиента
* Подключение Google Fonts
